坐标系转换

WGS-84(地球/GPS) / GCJ-02(火星/高德·腾讯) / BD-09(百度) 互转。支持批量: 每行一条 "经度,纬度"。

经纬度 ⇄ 度分秒

距离 / 方位角 / 偏移点

两点需在同一坐标系下; 方位角以正北为 0°, 顺时针 0-360°。

高斯-克吕格投影

经纬度 ⇄ 高斯平面坐标 (米), 支持测绘常用椭球与 3°/6° 带号。
